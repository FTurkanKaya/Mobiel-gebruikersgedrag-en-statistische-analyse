# Mobiel-gebruikersgedrag-en-statistische-analyse
Analyse van mobiel gebruiksgedrag en efficiëntie In dit project wordt het gedrag van mobiele gebruikers geanalyseerd op basis van app-gebruik, schermtijd, batterijverbruik en efficiëntiescores. Met segmentaties op geslacht, leeftijd, besturingssysteem en gedragsklasse worden inzichten verkregen in gebruikerspatronen.
